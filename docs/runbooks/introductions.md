# MCH-01 introductions runbook

Introduction batches are bounded to the configured maximum and refresh only after the stored
cooldown. PostgreSQL is authoritative; cursors are HMAC signed with the application pepper.

When candidates unexpectedly disappear, inspect current IAM state, VER community access, ELG mode
and partition decisions, SAF blocks/actions, active CON edges, and the current ONB discovery
preference version. Do not inspect or log decrypted preference values. A block or preference
change requires a new final gate and does not restore a prior decision.

If the CON materialization adapter is unavailable, mutual outcomes remain safe and no connection is
claimed. Retry the same payload-bound operation key; never replay with a new action on behalf of a
member.
